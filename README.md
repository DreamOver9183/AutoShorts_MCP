# AutoShorts-MCP

> AI 驅動短影音自動化剪輯系統 — 基於 Model Context Protocol (MCP) 標準。

由大型語言模型扮演「導演與剪輯師」，透過結構化工具呼叫驅動底層影音處理管線。
使用者提供素材資料夾、剪輯風格描述與音樂來源，系統自動完成視聽分析、節拍卡點編排，
並輸出 1080x1920 (9:16) 短影音或剪輯軟體草稿工程檔。

## 核心設計

* **雙軌輸出** — 軌道 A 產出 CapCut / 剪映草稿供無損微調；軌道 B 以本機 GPU 硬體編碼直出 MP4。
* **記憶體防爆** — 分段獨立子進程處理 + Concat Demuxer 無損拼接，峰值 RAM 控制於 3 GB 以內。
* **供應商中立** — 硬體編碼器啟動時自動偵測（`nvenc > qsv > amf > videotoolbox > vaapi > libx264`）；
  LLM 透過 Provider 抽象層接入，規格不綁定任何特定模型型號。
